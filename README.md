# Portfólio — Alexander Junior

Site pessoal com meu currículo, habilidades, experiência, formação e contato. Página única, em português com opção de inglês.

## Stack

- Bun + Turborepo (monorepo)
- React + Vite + Wouter (frontend)
- Hono (servidor)

## Rodar localmente

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run typecheck
```
